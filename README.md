# 🎟️ Sistema de Gestión para Rifa a Beneficio

Aplicación web desarrollada en **Python (Django)** y **Bootstrap** diseñada para simplificar el control, registro y seguimiento de números y pagos en rifas benéficas o comunitarias. 

Permite dejar el panel de administración tras bambalinas y ofrecer una interfaz pública, rápida y amigable para registrar compradores tanto de forma individual como por listas completas.

## ✨ Características Principales

* **Estructura Organizada:** Soporte para múltiples listas (ej. 60 listas) con 10 números cada una.
* **Venta Rápida (Tira Completa):** Opción de registrar el nombre, celular y marcar como pagados los 10 números de una lista de un solo golpe.
* **Control Individual:** Opción de gestionar números sueltos con actualización en tiempo real de su estado (Disponible ⚪ / Pagado 🟢) y fecha de transacción.
* **Interfaz Adaptada:** Diseño limpio y responsivo con Bootstrap 5, ideal para usar desde el celular o computador.
* **Panel de Administración (Django Admin):** Vista exclusiva para la administración general, supervisión de datos y respaldos.

---

## 🛠️ Tecnologías Utilizadas

* **Backend:** Python / Django
* **Frontend:** HTML5, CSS3, Bootstrap 5
* **Base de datos:** SQLite
